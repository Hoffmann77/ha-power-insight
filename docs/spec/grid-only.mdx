## Why this case exists

Every case needs something to be read against, and for a long time that job was
done by a four-adapter house. It should not have been. A single grid meter is
enough to give **every** property in the catalog a value — all four layers of
it, provenance and money included — which makes this the simplest place to see
what the engine does when there is nothing to be clever about.

Every answer here can be checked in your head: one source means a provenance row
of exactly `1`, no local generation means marginal and levelized cost agree, and
nothing is saved because there was nothing to save it against. Read the bigger
houses against it.

The third snapshot is the one worth arguing with. When the only meter drops
out, almost everything correctly reports nothing at all — and one rate reports
zero instead.
