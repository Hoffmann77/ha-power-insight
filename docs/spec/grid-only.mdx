## Why this case exists

Every case needs something to be read against, and for a long time that job was
done by a four-adapter house. It should not have been. A single grid meter is
enough to give **every** property in the catalog a value — all four layers of
it, provenance and money included — which makes this the cheapest place in the
corpus to settle what the engine does when there is nothing to be clever about.

That matters for certification rather than for reading. A value derived by hand
here takes a minute; the same rule checked in a six-device wiring takes an
afternoon and is easier to get wrong. So the degenerate answers are pinned here
and nowhere else: one source means a provenance row of exactly `1`, no local
generation means marginal and levelized cost agree, and nothing is saved
because there was nothing to save it against.

The third snapshot is the one worth arguing with. When the only meter drops
out, almost everything correctly reports nothing at all — and one rate reports
zero instead.
